📌 Overview

This project demonstrates an end-to-end data analytics workflow, starting from raw data processing to generating business insights through interactive visualizations. The objective is to analyze customer behavior and uncover patterns that can support data-driven decision-making.

🎯 Objectives
Understand customer purchasing behavior
Identify trends and patterns in sales data
Perform data cleaning and transformation
Extract insights using SQL queries
Build an interactive dashboard for visualization

🛠️ Tech Stack
Python (Pandas, NumPy, Matplotlib, Seaborn)
SQL (PostgreSQL)
Power BI
